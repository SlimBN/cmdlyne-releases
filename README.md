# Cmdlyne

A terminal for macOS that keeps every command with its output, sorts your tabs into spaces like Arc, and works with the Claude or ChatGPT plan you already have. Everything stays on your Mac: no account, no sync, no telemetry.

## Opening it the first time

Cmdlyne is signed for local use, so macOS asks before opening it the first time.

1. Open `Cmdlyne.dmg` and drag Cmdlyne to Applications.
2. Open Cmdlyne. macOS says it can't check it; click Done.
3. Open System Settings › Privacy & Security, scroll to Security and click **Open Anyway** next to Cmdlyne, then confirm.

After that it opens like any other app.
